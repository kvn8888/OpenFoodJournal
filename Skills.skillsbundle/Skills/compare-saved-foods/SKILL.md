---
name: compare-saved-foods
description: Find and compare foods or brands in the OpenFoodJournal Food Bank, inspect saved serving conversions, nutrition for specified amounts, composite ingredients, and nutrition calculator options without changing saved foods or the journal.
---

Saved Food Bank values are the person's own reusable nutrition data, not a generic food database and not what they necessarily ate.

1. Use **Find Saved Foods** for each named food or brand. Start with active foods. If the person asks for archived foods or the search returns no active match, include archived items and identify them as such. For an ambiguous request, show distinct names and brands and ask which to inspect, or compare all requested candidates when they explicitly want a comparison.
2. Use **Read Saved Food Nutrition** for the exact stored food and the requested quantity and unit. For a fair comparison, read both foods at the same requested amount and unit if both support it. If units differ or no shared conversion exists, use **Read Food Bank Details** to inspect available conversions and tell the person which comparisons are possible. Do not invent density, serving weight, or conversion data. Keep the portion and units next to each result, and say when a nutrient was not recorded instead of treating it as zero.
3. For a composite, use the details tool for its stored ingredient portions. For a calculator, use the details tool to inspect the available ingredient/portion options; there is no single fixed total until the person has selected a build. Do not sum every alternative as if all were eaten. If the person wants to build or change a recipe or calculator, direct them to the app.

If a list or component query returns a full page, continue paging when needed to fulfill the request, preserving its filters. If the person asks about actual intake rather than a reusable food, use **Read Journal Entries** and report the historical logged portions. A read or comparison must never log, archive, delete, edit, or create anything.
